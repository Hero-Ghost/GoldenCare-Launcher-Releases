# GoldenCare Launcher — ערוץ הפצה ועדכונים 📱

ערוץ ההפצה הרשמי של **GoldenCare Launcher** — מסך בית (Launcher) לאנדרואיד המותאם במיוחד לגיל השלישי, עם ממשק ענק, עברית מלאה (RTL), לחצן מצוקה ופשטות מקסימלית.

מאגר זה משמש להפצת קובצי ה-APK העדכניים של האפליקציה ולניהול עדכוני OTA (Over-the-Air).

## 📥 הורדה והתקנה

1. **הורידו את קובץ ההתקנה ישירות למכשיר:**  
   👉 **[GoldenCareLauncher.apk](https://raw.githubusercontent.com/Hero-Ghost/GoldenCare-Launcher-Releases/main/GoldenCareLauncher.apk)**
2. פתחו את הקובץ שהורד. אם תתבקשו, אשרו **"התקנה ממקורות לא ידועים"** עבור הדפדפן או מנהל הקבצים.
3. בסיום ההתקנה, לחצו על כפתור הבית (Home) ובחרו ב-**GoldenCare Launcher** ← **"תמיד"**.

## 🌟 מה חדש בגרסה 1.1.6?

- **התאמות מלאות למכשירי שיאומי (Xiaomi, Redmi, POCO) עם MIUI / HyperOS:**
  - **לחצני ניווט קלאסיים (חזור ובית):** פתיחה ישירה של הגדרות הניווט בלחיצה אחת כדי לעבור ממחוות (פס כמו באייפון) ל-3 לחצנים (כמו בסמסונג) עם כפתור חזור בצד ימין.
  - **הפעלה אוטומטית (Autostart):** קיצור דרך ייעודי להגדרת האפליקציה לפעול תמיד באתחול וברקע.
  - **ללא הגבלת סוללה (Battery Saver):** מעבר מהיר להגדרת "ללא הגבלות" כדי ששיאומי לא תרדים את הלאנצ'ר.
  - **הרשאות חלונות קופצים:** גישה מהירה לאישור "הצג במסך הנעילה" ו"חלונות קופצים ברקע" עבור קבלת שיחות נכנסות בצורה חלקה.
- **שדרוג חסימת וילון ההתראות:** חסימה הרמטית גם עבור מרכז הבקרה (Control Center) הייחודי של שיאומי.
- **בחירת יישומי ברירת מחדל משופרת:** גישה נוחה לבחירת מסך בית, חייגן ואפליקציית הודעות.

## ⚙️ מדריך מהיר להגדרת שיאומי (Xiaomi / Redmi / POCO)

במכשירי שיאומי מומלץ לוודא 3 הגדרות פשוטות (ניתן להגיע אליהן ישירות מתוך **הגדרות המנהל** בלאנצ'ר > **התאמות למכשירי שיאומי**):

1. **החזרת כפתורי הניווט (כמו בסמסונג):**  
   - הגדרות > מסך הבית > ניווט במערכת > בחרו **"לחצנים" (Buttons)** והפעילו **"היפוך לחצנים" (Mirror buttons)**.
2. **הפעלה אוטומטית (Autostart):**  
   - הגדרות > אפליקציות > ניהול אפליקציות > GoldenCare > הפעילו **הפעלה אוטומטית**.
3. **חיסכון בסוללה:**  
   - באותו מסך, תחת "חיסכון בסוללה", בחרו **"ללא הגבלות" (No restrictions)**.
4. **שיחות נכנסות מעל הנעילה:**  
   - הרשאות נוספות > סמנו פעיל ב-"הצג במסך הנעילה" וב-"הצג חלונות קופצים בזמן פעולה ברקע".

## 🔄 עדכונים אוטומטיים (OTA)

- **בדיקה אוטומטית ברקע:** האפליקציה בודקת מול מאגר זה קיומם של עדכונים חדשים.
- **בדיקה יזומה והתקנה בקליק:** דרך מסך ההגדרות (קוד PIN) תחת "עדכוני מערכת" ← "בדיקת עדכונים עכשיו" ← "הורד והתקן".
