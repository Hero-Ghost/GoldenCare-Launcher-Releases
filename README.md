# GoldenCare Launcher — ערוץ הפצה ועדכונים

ערוץ ההפצה הרשמי של GoldenCare Launcher, מסך בית (Launcher) לאנדרואיד המותאם לגיל השלישי.

מאגר זה משמש להפצת קובצי ההתקנה של האפליקציה ולניהול עדכוני OTA (Over-the-Air). קוד המקור מתוחזק במאגר נפרד.

---

## גרסה נוכחית

| פרט | ערך |
|---|---|
| גרסה | 1.0.0 |
| סטטוס | גרסה יציבה |
| תאימות | Android 8.0 (API 26) ומעלה |

## הורדה והתקנה

1. הורידו את קובץ ההתקנה: **[GoldenCareLauncher.apk](https://raw.githubusercontent.com/yakir054616-creator/GoldenCare-Launcher-Releases/main/GoldenCareLauncher.apk)**
2. פתחו את הקובץ במכשיר. אם תתבקשו, אשרו התקנה ממקורות לא ידועים עבור הדפדפן או מנהל הקבצים.
3. בסיום ההתקנה, הגדירו את GoldenCare Launcher כמסך הבית של המכשיר.

## עדכונים אוטומטיים


- **בדיקה אוטומטית** — פעם ב-24 שעות לכל היותר, לשמירה על צריכת סוללה ונתונים נמוכה.
- **בדיקה יזומה** — ניתן לבדוק עדכונים בכל עת דרך מסך ההגדרות.

כאשר קיימת גרסה חדשה, תוצג התראה באפליקציה וניתן יהיה להתקין את העדכון ישירות מתוכה.
